# War: The Card Game

A C# desktop version of the card game War, created for an application development project. Players reveal cards each round, and the higher card wins. The game displays the results after the selected number of rounds.

## Features

- Play against the computer or another player
- Choose a game length of 5, 10, or 15 rounds
- Set player names
- Switch the interface between English, French, and Spanish
- Turn music on or off
- View round results and the final card counts
- Restart a game or return to the main menu

## Technology

- C#
- Visual Studio
- Desktop graphical interface

## Run the project

1. Download and extract [`WarCardGameProject.zip`](WarCardGameProject.zip).
2. Open the extracted project in Visual Studio.
3. Build and run the application.

For gameplay instructions and screenshots, see the [user manual](User%20Manual.docx).
